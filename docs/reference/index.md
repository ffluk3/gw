# Reference

Reference pages describe the tool precisely. Use them for lookup, not for
learning. Each fact on these pages is a behavior of the installed binary.

- [Command-line reference](cli.md) — each command, flag, and output shape.
- [Configuration reference](configuration.md) — `.gw.toml`, `~/.gw.toml`, the
  convention rules, and each environment variable.
- [Layout on disk](layout.md) — the directory convention and the discovery
  rules.
- [Exit codes](exit-codes.md) — the meaning of each code.
- [JSON output](json.md) — the stable machine-readable shapes.
